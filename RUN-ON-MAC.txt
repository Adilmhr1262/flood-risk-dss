FloodSafe Pakistan (Flood Risk DSS) - run notes
=============================================

This is the disaster-management project: data-driven flood risk prediction
and early warning decision support system (FastAPI + PostGIS backend,
Next.js web, Flutter mobile).

Quickest way to see it: Docker.
  cd flood-risk-dss
  docker compose up

Manual backend run (needs Python 3.12 and a local PostgreSQL 16 + PostGIS):
  cd backend
  python3 -m venv .venv
  source .venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env   (then edit DB credentials inside)
  .venv/bin/uvicorn app.main:app

Web frontend:
  cd web
  npm install
  npm run dev

Full details are in README.md and docs/.
Note: backend/.env was NOT included in this zip (it holds secrets).
Create it from backend/.env.example.
